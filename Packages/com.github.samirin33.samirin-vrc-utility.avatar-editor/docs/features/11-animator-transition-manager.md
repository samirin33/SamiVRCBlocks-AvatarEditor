# Animator Transition Manager

## 概要

選択中ステート/トランジションの遷移一覧を表示し、順序変更・並列遷移追加・条件編集・コピー/ペーストをまとめて行う管理ウィンドウです。

## 開き方

- メニュー: `samirin33 Editor Tools/Animator/トランジション管理ウィンドウ`
- Animator でステートまたはトランジションを選択した状態で開くと、対象の一覧が表示されます。

## 使い方

### 基本手順

1. Animator で対象ステート（またはトランジション）を選択する
2. 必要に応じて行番号ドラッグで順序変更、`トランジションを追加` で並列追加、設定・条件パネルで編集する

### オプション・設定

- 行番号クリックで編集対象を切り替え、複数選択編集にも対応します。
- 同一グループ（State / Any State / Entry）単位で順序を再構築します。
- サブステート内の非デフォルトステートを選択中は、`サブステート内のデフォルトステートにする` ボタンが表示されます。
  - 実行するとそのサブステートマシンの default state に設定し、ステート配列の先頭（最古扱い）へ移動します。

## 注意事項

- サブステート内の非デフォルトステートを選択中は現在使用後すぐに描画が反映されません。(内部的に処理は成功していいるので次に何かしらアクションすると反映されます)
