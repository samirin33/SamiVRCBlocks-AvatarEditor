# Image Compressor

## 概要

**画像アセットのリサイズ・形式変換・圧縮**を行うエディタウィンドウです。複数画像をまとめて処理しつつ、必要に応じて個別設定もできます。ピクセル数とファイルサイズの削減に使います。

## 開き方

- メニュー: **`SamiVRCBlocks-AvatarEditor`** → **`Performance`** → **`Image Compressor`**
- Project ビューで画像やフォルダを選択した状態で **`Assets`** → **`samirin33`** → **`Compress Images`**（ウィンドウを開き、選択内容を追加）
- ウィンドウタイトル: **Image Compressor**

## 使い方

### 基本手順

1. 対象画像を追加する（次のいずれか）
   - **画像** / **フォルダ** の Object フィールドから追加
   - **選択中のアセットを追加**
   - Project ビューからウィンドウへ **ドラッグ＆ドロップ**
2. **一括設定**で縮小倍率・出力形式・保存方法などを決める
3. 必要なら各画像の折りたたみを開き、**個別調整する**にチェックして上書き設定する
4. **圧縮・変換を実行**を押す
5. 結果サマリーで成功件数・合計サイズの変化を確認する

### 一括設定

| 項目 | 説明 |
|------|------|
| **縮小倍率** | 0.05〜1.0。プリセットボタン **50%** / **25%** あり |
| **出力形式** | 元の形式を維持 / PNG / JPG |
| **JPG 品質** | JPG 出力時（および元形式維持で JPG の場合）の品質 1〜100 |
| **最大辺サイズを制限する** | 長辺を 128〜4096 px に制限 |
| **保存方法** | **上書き** / **コピーとして保存**（サフィックス既定: `_compressed`） |

一括設定の変更は、「個別調整する」にチェックしていない項目へ自動反映されます。**一括設定を全件に適用**で、個別調整も含めて強制上書きできます。

### 対象リスト

- 各行で有効/無効、プレビュー、元解像度・ファイルサイズを確認できます
- **すべて有効** / **すべて無効** / **無効を削除** でリストを整理できます
- 個別折りたたみ内で倍率・形式・最大辺などを上書きできます

### 対応形式

入力として扱える拡張子の例: `.png` / `.jpg` / `.jpeg` / `.tga` / `.tif` / `.tiff` / `.bmp` / `.exr` / `.gif`

## 注意事項

- **上書き**は元ファイルを直接書き換えます。必要に応じて事前にバックアップや版管理で復元できるようにしてください
- 処理後はインポート設定の再適用が発生します。大きな画像を多数処理する場合は時間がかかることがあります
