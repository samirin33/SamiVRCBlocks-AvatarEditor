# AnimatorStateController

## 概要

Animator内のステートやトランジション設定をインスペクターに代わって編集しやすくしたものです。

## 開き方

- メニュー: **`SBAvatarEditor`** → **`Animation`** → **`AnimatorStateController`**
- Animatorウィンドウと一緒に利用する必要があります。

## 主な表示・編集機能

1. **ステート設定**
1. **外向き／内向きトランジションのリスト**
1. **トランジション設定・条件**
1. **Behaviour**
1. **クリップボード**

## 使い方

### トランジション一覧

- ステートを選択した場合、ステートから伸びるトランジションの**外向き**と
ステートへ伸びてくる**内向き**をリスト表示します。
それぞれの要素は選択、入れ替えができます。この順序は上から優先度が高いです。
- リスト下の **「トランジションを追加」** で、すでにあるトランジションと同じ経路のトランジションを追加できます。
- トランジションを選択しているときのリストは設定順です。優先度とはまた別の順序であることに注意してください。

### トランジション設定・条件

- 上記リストで選択されている要素のトランジション設定を編集できます。
複数選択されている場合はまとめて編集できます。

### サブステート内の「デフォルト」にする

- **非ルート**の**サブステートマシン**内で、**まだデフォルトではない**ステートを選んでいるとき、**「サブステート内のデフォルトステートにする」** ボタンが表示されます。使用するとサブステート内のEntryから伸びるデフォルトトランジションの遷移先を変更できます。[注意事項](##制限・注意)

### ステート設定（`AnimatorState` 選択時）

- inspectorで編集できる内容と同等のステート設定を行えます。

### Behaviour

- 選択中のステートにある**StateMachineBehaviour**を追加・編集・削除できます。

## 制限・注意

- **「サブステート内のデフォルトステートにする」**を使用した直後は描画が反映されません。内部的な処理は完了しているので次回の画面が更新されたタイミングで反映されます。
