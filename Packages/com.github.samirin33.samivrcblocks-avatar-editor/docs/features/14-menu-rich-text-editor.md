# Menu Rich Text Editor

## 概要

**MA Menu Item** と **VRC Expressions Menu** の表示名を、TextMeshPro のリッチテキストとして編集・プレビューするエディタウィンドウです。太字・色・サイズなどのタグをボタンから挿入し、VRChat の Expression Menu に近い見た目で確認してから書き込めます。

## 開き方

- メニュー: **`SBAvatarEditor`** → **`Menu`** → **`Rich Text Editor`**
- MA Menu Item のコンテキストメニュー: **`SBAvatarEditor`** → **`Rich Text を編集`**
- VRC Expressions Menu アセットのコンテキストメニュー、または **`Assets`** → **`SBAvatarEditor`** → **`Edit Menu Rich Text`**
- ウィンドウタイトル: **Menu Rich Text**

## 使い方

### 基本手順

1. Hierarchy で **MA Menu Item** を選ぶか、Project で **VRC Expressions Menu** を選ぶ（アバタールートを選ぶと配下をまとめて収集します）
2. 対象リストから編集したい項目を選ぶ
3. **見た目**欄でリッチテキストの表示を確認し、**ソース（タグ付き）**欄で文字をドラッグ選択して書式を適用する
4. **変更を自動書き込み** がオンならその場で保存されます。オフのときは **対象に書き込む** を押します
5. 変更は **Undo / Redo**（`Ctrl+Z` / `Ctrl+Y` または Edit メニュー）で戻せます（記録名: Menu Rich Text）

### 対象

| 対象 | 書き込み先 |
|------|------------|
| MA Menu Item の名前 | `label`（空のときは GameObject 名が表示に使われます） |
| MA / VRC のパペット軸ラベル | `Control.labels[].name` |
| VRC Expressions Menu の Control | `controls[].name` |

- **選択を追従**: Unity の選択変更に合わせて対象を更新します
- **label を空に**: MA で GameObject 名に戻したいときに使います

### 画面レイアウト

| 位置 | 内容 |
|------|------|
| 左 | **オブジェクトリスト**（対象の選択・絞り込み） |
| 右上 | **プレビュー**（リッチテキスト見た目） |
| 右中 | **本文**（タグ付きソース。ここで選択して書式適用） |
| 右下 | **書式**（太字・色・サイズなどのツール） |

### 書式ツール

| 操作 | 内容 |
|------|------|
| B / I / U / S | 太字・斜体・下線・取り消し線。同じボタンで解除。選択範囲にタグがあるときはボタンが強調表示されます |
| x₂ / x² | 下付き / 上付き |
| マーク | ハイライト `<mark=#RRGGBB>` / `<mark=#RRGGBBAA>`。色とアルファを指定して適用／解除。適用は既存タグを更新（同じ値でも解除しない） |
| 色 / パレット / HEX | `<color=#RRGGBB>` / `<color=#RRGGBBAA>`。アルファ対応。適用は既存タグを更新。解除は **色解除**。パレット右に適用色の履歴（最大10・重複なし） |
| サイズ % | `<size=80%>` など。適用は既存タグを更新。解除は **解除**。50%〜150% のプリセットあり |
| voffset | 上下位置（em）。適用は既存タグを更新。解除は **解除** |
| グラデ | 単色の下。Gradient フィールドで色を指定し、右の適用で文字ごとに着色。選択するとグラデ範囲として認識しフィールドに反映 |
| 全削除 / 選択範囲削除 | 全体または選択範囲内の見た目用タグを除去 |

### プレビュー

- 上欄の見た目は TextMeshPro で描画します（`NotoSansJP-Medium.ttf` を使用）
- 本文で範囲選択してから書式ボタンを押すと、その部分だけにタグが付きます

## 注意事項

- MA のリッチテキストは GameObject 名ではなく **label** に保存します。
