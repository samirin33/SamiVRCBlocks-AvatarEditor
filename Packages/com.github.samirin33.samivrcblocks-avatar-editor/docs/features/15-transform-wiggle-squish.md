# Transform Wiggle / Squish

## 概要

**Transform Wiggle / Squish** は、Transform のローカル位置またはローカル回転を揺らすウィグル、あるいはローカルスケールを潰して戻すスクウィッシュの AnimationClip を作るエディタウィンドウです。振幅・ノイズ・振動数・ベース・減衰率・ベースへ戻す閾値・X/Y/Z の時間のずれをスライダーで調整し、シーン上でプレビューしてからクリップへ書き込めます。

波形は次の式です。

`ベース + (振幅 × sin(2π × 振動数 × (時間 + 時間のずれ)) + ノイズ) × exp(-減衰率 × 時間)`

ループでないとき、残りの振れ幅（`(|振幅| + |ノイズ|) × exp(-減衰率 × 時間)`）が閾値を下回った時刻でカーブを終え、最後のキーをベースにします。

## 開き方

- メニュー: **`SBAvatarEditor`** → **`Animation`** → **`Transform Wiggle Squish`**
- ウィンドウタイトル: **Wiggle / Squish**

## 使い方

### 基本手順

1. Animation ウィンドウで、動かすオブジェクトとクリップを開く。階層で選んだ行が対象、ウィンドウのルートが基準、開いているクリップが書き込み先になります
2. **位置ウィグル**、**回転ウィグル**、**スケールスクウィッシュ** のいずれかを選ぶ
3. 左のグラフを見ながら右のスライダーを動かし、**プレビュー** でシーン上の動きを確認する
4. **編集中のクリップに適用** で、Animation ウィンドウの再生位置からそのクリップへ書き込む

プレビュー中の姿勢は、停止するとプレビュー前に戻ります。クリップの中身は適用するまで変わりません。プレビューを始めるとき、Animation ウィンドウがプレビュー中なら、そのプレビューを止めてから再生します。ループをオンにしたプレビューは、末尾で待たずに先頭へ戻り、波形がつながります。

### オプション・設定

- **振幅 X/Y/Z**: その軸の振れ幅です。位置とスケールのスライダーは -1 から 1、回転は度で -45 から 45 です。左の数値欄には範囲外も入れられます。スクウィッシュでは、Y を正、X/Z を負にすると潰れて広がります
- **ノイズの強さ**: 3軸に同じ強さで足す滑らかな乱数です。位置とスケールのスライダーは 0 から 1、回転は 0 から 15 度です。数値欄には範囲外も入れられます。0 ならノイズはありません
- **ノイズの周波数 (Hz)**: 3軸共通のノイズの細かさです。スライダーは 0 から 30 で、数値欄には範囲外も入れられます。ループ中はクリップ一周でつながり、先頭と末尾が同じになります
- **シード / ランダム**: 同じシードなら同じノイズです。**ランダム** で別の形に切り替えます
- **Yを主軸にスクウィッシュ配分**: スケールスクウィッシュのときだけ出ます。Y の振幅を主軸にし、X と Z をその半分の逆符号にします
- **振動数 (Hz)**: 1 秒あたりの往復回数
- **減衰率**: 大きいほど速く小さくなります。包絡線は `exp(-減衰率 × 時間)` です。0 で減衰しません。ループ中は使いません
- **終了閾値**: 減衰した振幅とノイズの合計がこの値を下回った時刻でカーブを終え、最後のキーをベースにします。0 では上限時間まで続きます。ループ中は使いません
- **上限時間**: 閾値まで戻る前に、この秒数で打ち切ります
- **ベース**: 揺れの中心です。位置ウィグルでは位置、回転ウィグルではオイラー角（度）、スケールスクウィッシュではスケールだけを表示します。**現在値** で対象の現在値を入れます
- **時間のずれ X/Y/Z（秒）**: 軸ごとに波形を前後へずらします。**1/4** は全軸に 4 分の 1 周期を足し、山に近い姿勢から始められます
- **サンプルレート**: 最適化しないときの、1 秒あたりのキー数です。キーの接線は波形の微分に合わせます
- **キーを最適化**: 初期状態でオンです。波形との誤差が許容範囲に収まるベジエハンドルを計算し、必要なキーだけを置きます
- **許容誤差 (%)**: 最適化したときの誤差の上限です。波形の大きさに対する割合で、小さいほどキーが増えます
- **ループ**: 減衰と閾値を使わず、周期の整数倍でつながる波形にします。クリップの Loop Time もこの設定になります。プレビューは末尾で止まらず、先頭の姿勢へつながります
- **ループ周期数**: ループ時の繰り返し回数。クリップ長は `周期数 / 振動数` です

ベース位置・スケール・時間のずれがスライダー範囲の外にあるときは、数値入力に切り替わります。振幅とノイズの強さ、ノイズの周波数は、スライダーとは別に数値欄があり、そこへ範囲外の値を入れられます。

グラフはベースからの変位です。0 がベースで、X が赤、Y が緑、Z が青です。

### 初期値

**初期値** は、選択中のモードの振幅や振動数などを戻します。ベースは上書きしません。

- **位置ウィグル**: ベース姿勢から始まる、小さめの位置揺れ
- **回転ウィグル**: 度単位のローカル回転の揺れ
- **スケールスクウィッシュ**: Y を伸ばし X/Z を縮め、山に近い姿勢からベースへ戻るスケール

### 書き込み

- 位置ウィグルは `m_LocalPosition`、回転ウィグルは `localEulerAnglesRaw`（度）、スケールスクウィッシュは `m_LocalScale` です
- 同じクリップに位置・回転・スケールを順に適用すると、それぞれのカーブは残ります
- 同じパス・同じ種類のカーブがあるときは、上書きを確認します
- 対象は Animation ウィンドウの階層で選択中のオブジェクト、基準ルートはそのウィンドウのルート、クリップは開いているクリップです
- バインドパスは、基準ルートから対象までの相対パスです
- 終了閾値を下回った時刻が、このモーションの最後になり、そのキーはベースです
- 最初のキーは、適用した瞬間の Animation ウィンドウの再生位置に置きます。その範囲より前や後ろにある、同じカーブの既存キーは残します
- クリップ内の他のカーブがそれより長い場合、クリップ全体の長さはそちらに合わせます
- **キーを最適化** がオンのときは、各区間を 3 次ベジエ（ハンドルの長さは区間の 1/3、傾きは波形の微分）で表し、許容誤差を超える区間だけを分割します

前回のスライダー値は EditorPrefs に保存されます。対象・基準ルート・クリップは Animation ウィンドウの状態に追従します。

## 注意事項

- プレビューはエディタ専用です。シーンを再生する前にプレビューは止まります
- Humanoid の人型ボーンでは、位置とスケールのカーブが Animator に無視され、回転は筋肉に置き換わることがあります。追加ボーンや Generic 向けです
- スケールの振幅が大きいと、スケールが 0 以下になってメッシュが反転することがあります
- ループをオフにして適用すると、クリップ全体の Loop Time もオフになります
- FBX など編集できないクリップには書き込めません
- キー数が多すぎる場合は、クリップ長を自動で短くします
