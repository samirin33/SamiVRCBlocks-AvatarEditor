# ループキー

## 概要

Animation ウィンドウで編集中のクリップに、自然なループ用のキーを追加するエディタウィンドウです。各フロートカーブの終点から始点へ戻る三次ベジエを、指定したクリップ長の最初と最後のフレームへ同じ値・同じ接線で置きます。

## 開き方

- メニュー: **`SBAvatarEditor`** → **`Animation`** → **`Loop Key`**
- ウィンドウタイトル: **ループキー**

## 使い方

### 基本手順

1. Animation ウィンドウで対象のクリップを開く
2. **ループキー** ウィンドウでクリップ長を秒またはフレームで指定する。初期値は現在のクリップ長です。フレーム数はクリップのフレームレートで秒に換算します
3. **ループキーを追加** を押す

`t = 0` と指定した長さ `L` は、ループ再生では同じ瞬間です。この 2 つのキーは同じ値、同じ接線になります。

ループ区間は、終点からクリップ末尾を通り、先頭から最初のキー（始点）へ戻る時間です。終点は、指定した長さより後にキーが無いときは最後のキー、あるときは長さより前の最後のキーです。継ぎ目の値はそのベジエ上の位置、接線はその点の微分 `dy/dt` です。終点の out 接線と始点の in 接線が、このベジエの制御点になります。分割後もその形を保つため、終点の out 側と始点の in 側のハンドルも短くします。始点の out、終点の in、その間のキーの値は変えません。途中キーの接線モードは、形が変わらないように Free へ固定します。

### オプション・設定

- **クリップ長（秒）** と **クリップ長（フレーム）**: ループキーを置く末尾。どちらかを変えると、もう一方も同じ長さになります。フレームは `フレーム数 / フレームレート` 秒です
- **Loop Time を有効にする**: オンのとき、クリップの Loop Time を有効にします。クリップ範囲の開始は 0、終了はこの長さになります

指定した長さより後にキーがあるカーブは、長さ以降のキーを削除してから作ります。終点はそのとき、長さより前にある最後のキーです。

始点がすでに 0 で終点だけが長さより前のときは、始点の値と in 接線を末尾へ複製します。終点がすでに長さ上で始点だけが 0 より後のときは、終点の値と out 接線を先頭へ複製します。接線が無限大の定数キーは、終点の値を保持する定数キーとして空き側の端へ置きます。

## 注意事項

- 始点と終点がすでにクリップの両端にあるカーブは、戻る区間がないためスキップします。長さを終点より長くするか、始点を 0 より後にしてから実行してください
- 一度追加したあとは、両端のキーが始点と終点になるため、同じ長さでもう一度実行するとスキップされます
- オブジェクト参照のカーブは対象外です。カーブごとに区間を見るため、一部だけスキップされることがあります
- FBX など編集できないクリップには書き込めません
- 0 より前にキーがあるカーブはスキップします
- 指定した長さより前にキーが無いカーブはスキップします
- 適用は Undo できます
